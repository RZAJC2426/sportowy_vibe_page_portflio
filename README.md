# Sportowy Vibe page

Strona internetowa projektu Sportowy Vibe, koncentrującego się na informacjach i relacjach ze świata sportu. Głównymi odbiorcami są Polonia na całym świecie oraz osoby podróżujące w drodze do pracy lub rekreacyjnie.

**Wersja online:** https://sportowyvibe.pl/
**Status:** wersja beta, niektóre elementy mogą nie być w pełni funkcjonalne.

## Technologie
React 19, TypeScript, Vite, Tailwind CSS, React Router, i18next, Supabase. Strona została wygenerowana w Readdy.ai.

## Mój wkład
Modyfikacja linków i ikon (większość ikon jest mojego autorstwa) oraz przygotowanie wersji do portfolio.

## Funkcje
- Logowanie: bezpośrednio na stronie, przez konto Google lub metodą biometryczną/kodem PIN
- Zegar, data i pogoda w górnym pasku
- Przełącznik motywu i języka
- Ułatwienia dostępu: tryb wysokiego kontrastu i zmiana rozmiaru tekstu

## Struktura strony
- Strona główna
- Aktualności (kanał projektu i podsekcje z dyscyplinami)
- O nas (Twórcy, Historia, Moderatorzy, Statystyki, Współpraca, Rezerwacja spotkania)
- Certyfikacja
- Kontakt

## Uruchomienie lokalne
1. `npm install`
2. Skopiuj `.env.example` do `.env` i uzupełnij własne dane
3. `npm run dev`

Dodatkowo: `npm run build`, `npm run lint`, `npm run type-check`.
